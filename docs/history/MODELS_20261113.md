# Model weights

> Current release selection: official HoloMotion G1 v1.4 `model_14000` and the matching plugins in `resources/holomotion_weights_manifest.json`. See [HoloMotion release status](HOLOMOTION_RELEASE_STATUS.md). Self-trained MoE-MLP / v2.4 configurations and weights described below are historical artifacts, not the default release.

## Current HoloMotion models

| Path | Contents |
|---|---|
| `checkpoints/holomotion_v1.4/config.yaml` | Official v1.4 network configuration |
| `checkpoints/holomotion_v1.4/model_14000/actor/model.safetensors` | Official frozen public Actor |
| `checkpoints/holomotion_v1.4/model_14000/critic/model.safetensors` | Official Critic required by the current strict loader |
| `checkpoints/holomotion_experts/<task>.domain.pt` | 12 independently trained plugins matching that public Actor |

Verify with `python tools/verify_weights.py --manifest resources/holomotion_weights_manifest.json`.
The 12 task plugins are staged locally. Official Actor/Critic weights are not
included; users download them directly using [the official download guide](HOLOMOTION_DOWNLOAD.md).
The manifest records required upstream hashes, not a claim that those official
weights are bundled. The simulator also needs the external runtime sources in
the release audit. No upload was performed.

## Historical self-trained v2.4 models

Model files are prepared locally for review under `checkpoints/`. They have not been uploaded. Exact file hashes, source checkpoints and historical evaluation status are recorded in [the weight manifest](../../resources/weights_manifest.json).

## Networks

| Files | Contents |
|---|---|
| `checkpoints/base/best.pt` | Selected iteration-11,000 base: EMA Actor (`pi`), live Actor (`pi_live`), world model (`wm`), Critic and optimizer states |
| `checkpoints/experts/<task>/` | 29 existing DAgger plugin checkpoints; the ATHLETE file is a failed-run last checkpoint |
| `checkpoints/experts/martial_ppo/` | Martial expert, separate Critic and optimizer states; 48,000 Actor Adam updates |
| `checkpoints/composed/pera_30_experts.pt` | One frozen public inference Actor and 30 installed competitive experts; at most one enabled; defaults all off |
| `checkpoints/ablations/` | Selected competitive and continuous-fusion stair plugins; 9,000 Adam updates each |
| `checkpoints/consolidated/` | Two full-Actor inference exports; public weights were trainable in this separate extension |

The full-Actor exports and switched bank omit optimizer state and preserve the source Actor tensors exactly. They are inference files, not optimizer-resume checkpoints. The switched bank contains the 29 listed DAgger checkpoints plus the martial PPO expert; it excludes routing ablations and full-Actor consolidation experiments. Other files retain their original checkpoint bytes. No source weight was changed.

The base checkpoint already contains the public FFNs, shared FFN, router, encoders, output head, world model and Critic. Separate copies of those same tensors are unnecessary. Frozen visual encoders and normalization for external task context still require the matching teacher resources in [resource setup](RESOURCES.md). The 8,626 parent is an optional separate resource for staged base-pretraining reproduction.

## Verification and loading

```bash
python tools/verify_weights.py
python tools/verify_expert_bank.py --report runs/expert_bank_check.json
```

Each plugin must use the matching base and its recorded context dimension. A competitive plugin, a fusion plugin and a full-Actor export have distinct checkpoint formats. The canonical loaders are `pera.routing.load_base`, the suite31 `Actor` wrapper, the stair A/B loader and the full-Actor `load_actor` respectively. The public Actor digest is checked before a frozen plugin is loaded.

The model files remain ignored by Git. Motion data and robot meshes are separate. The code MIT license does not relicense model weights, datasets or external teacher features; applicable source and dataset terms remain in effect.
